# 1.0.0 · 世界站

世界站 1.0.0。欢迎体验和反馈，不建议在没有备份的情况下迁移唯一一份重要存档。

## 本轮主要内容

- 使用 World Card Station（世界站）品牌分发 Windows、macOS 和 Linux 客户端。
- 导入原生游戏卡包，或选择项目 `card.json` 导入完整目录。
- 将 V2/V3 酒馆 JSON、PNG/APNG、CHARX 转换为原生卡，支持世界书、常见宏和部分正则规则。
- 客户端自带离线开发包，支持 Agent 项目初始化、真实平台语法 dry-run 和开发者模式运行日志。
- 随开发包分发 worldbook / timeline 可复用库及对应文档。

## 安装与升级

安装包选择和系统提示处理见 [README 安装 FAQ](../../README.md#安装-faq)。
升级前退出客户端并备份应用数据目录；沿用原数据标识，旧版 ChatApp 的配置和存档仍从原位置读取。
请保留升级前备份，回退版本不保证能读取新存档。此版本重新从 1.0.0 编号；旧 ChatApp 1.0.x 用户如遇安装器版本检查拦截，请先备份数据再卸载旧客户端，不要删除应用数据目录。

## 已知边界

- 酒馆导入不是完整 SillyTavern 运行环境：不支持插件、完整预设、群聊及所有宏扩展。
- 世界书写变量宏不执行；部分正则会永久改写历史消息，无法恢复原文。
- 跨正则共享 CSS 动画名称可能无法正确关联；遇到样式差异请提供可分发的最小复现。
- dry-run 检查语法，不执行剧情或调用模型，不保证实际游玩符合作者预期。
- 开发日志包含完整消息与 state，目前不自动轮转；分享前检查隐私。
- 模型服务需自行配置，效果和调用费用取决于模型服务与游戏卡。
