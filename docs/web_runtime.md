# Web 模型、规则与演出运行

## 游玩入口

Web 直接挂载与客户端相同的 App、聊天顶栏、游戏卡选择器和右侧设置面板，不另设预览首页。点击顶栏游戏卡名称打开选择器，查看托管卡封面与版本；选择后检查固定 release 的全部资源、补齐缓存并预加载规则，进度与取消按钮显示在原选择器内。选择“普通聊天”退出当前游戏卡，不删除缓存。

游玩时消息、变量、阅读位置和 retry base 在内存中变化；玩家打开与客户端相同的会话面板，点击“存档”后才在 IndexedDB 创建新的完整快照，不覆盖旧档。顶栏不另设保存按钮。刷新恢复本页最近一次存档，未存档的修改会丢失。切卡和切会话直接执行，不弹窗、不自动存档；刷新或关闭页面仍有浏览器补充提醒。详见 [Web Session 与显式保存](./web_sessions.md)。

Web 复用 `ChatRuntime`、`sendPipeline`、state patch、分段阅读、响应校验和重试，不另写规则引擎。`savePolicy: manual` 阻止初始化和运行中的自动保存；桌面仍使用 `automatic`。共享卡片选择器在 Web 隐藏本地导入、酒馆更新和卸载入口；设置隐藏开发指引，顶栏保留 Session 管理但隐藏磁盘 trace，不订阅原生关闭事件。

## 模型与密钥

右侧“系统配置”沿用客户端的背景、主题和模型设置。点击字段编辑 URL、密钥、模型名、OpenAI/Anthropic 协议和生成参数，失焦或 Enter 后应用并保存设置，不增加 Web 专属设置区。点击模型“已配置”状态测试连接；它走相同生成链路，会发送极短请求，真实服务可能收费。

`src/web/modelFetch.js` 使用浏览器 fetch，复用共享请求构造、参数处理和 SSE parser。请求不携带站点 cookie，不跟随重定向；Anthropic 请求添加浏览器直连声明头。服务端必须允许当前页面来源及所需请求头，静态主站不代理请求或接收密钥。

默认总超时 120 秒，覆盖连接和流读取。用户取消与超时分别提示；HTTP 错误保留供应商信息，网络或跨域失败合并提示，不断言一定是 CORS，也不使用 `no-cors` 绕过浏览器限制。流异常和用户取消沿用共享管线的消息、状态和演出恢复语义。

密钥默认随模型配置写入 IndexedDB，刷新或重新打开页面后恢复。清空 API Key 字段并应用后，同时清空当前和持久化密钥。持久化失败显示错误，不伪报成功；本地保存不是加密保险箱，可信卡的动态代码也不是隔离恶意脚本的安全沙箱。

## 浏览器存储

`WorldCardStationWeb` 版本 3 包含 `cardReferences`、`settings`、`backgrounds` 和 `sessions`。升级不删除已有记录。连接收到 versionchange 即关闭；升级被旧页面阻塞时提示关闭旧页面后重试。

模型配置以 `settings/model` 保存，包含 `apiKey` 字段，不再使用 `rememberKey` 开关。背景以 `backgrounds/current` 保存图片 Blob 和透明度，不持久化临时对象 URL。允许 20 MB 以内 PNG/JPEG/WebP/GIF/BMP；读取后创建本页 Blob URL，替换或清除时撤销旧 URL。卡片背景仍优先于用户背景。

## 脚本与演出

- exec 使用与桌面相同的受控 Worker、上下文校验、include/文件授权和默认 2 秒超时；死循环会终止 Worker。
- 自定义 React UI 复用 `GameCardUIRoot`，通过 `emit` 修改变量、执行脚本或发送消息；卡片源码要求浏览器安全 JS，不直接执行 JSX。
- 背景、立绘和 BGM 从已缓存的授权资源读取 Blob URL，不在演出时访问托管资源网络。
- Web 图片解码完成后才发布新画面。异步结果按请求版本检查，旧请求不覆盖新画面；失败保留之前画面，显示重试入口，不回滚已提交游戏状态。
- BGM 加载/解码失败可点击重试；自动播放被拒绝时提示手动播放，点击时直接调用播放接口，不通过绕过浏览器策略的参数解锁。
- 不提供独立全屏按钮，可使用浏览器全屏快捷键；现有 F11 适配使用 Fullscreen API，不支持或拒绝时记录错误，不模拟原生窗口操作。

缓存被浏览器回收时资源接口仍明确报错，需要重新进入游戏以检查并补齐缓存。切换前可保存进度，重新进入后恢复存档；尚无运行中无损缓存修复能力。

## 验证边界

`npm run test:web` 包含单元、真实浏览器集成和生产页面 E2E。模型测试服务使用与网页不同端口的 origin，真实验证 OPTIONS、允许/拒绝 CORS、两种协议流、错误、超时与取消；不使用真实密钥。

浏览器测试实际执行 Worker、Cache Storage、IndexedDB 和媒体。生产页面测试覆盖下载到游玩、UI 状态事件/脚本、两轮生成、变量 patch、背景/立绘、音频、失败重试及密钥刷新行为。共享场景将实际浏览器 Worker 管线结果与 Node VM 的桌面共享管线基线逐阶段比较消息和状态；它不替代真实 Tauri WebView E2E。

浏览器矩阵、真实模型、实际托管 CSP 和完整桌面验收仍按[开发计划](./web_development_plan.md)执行。不将单个 Chrome 的自动化结果视为所有浏览器或正式部署已经通过。
