# Web Session 与显式保存

Web 与客户端共用消息、变量、阅读和重试管线，但采用手动保存策略；普通聊天也不会自动保存。客户端继续自动保存。存档仅保存在当前浏览器，清理站点数据会丢失存档，不自动跨设备同步。

## 玩家操作

- 顶栏和菜单与客户端保持一致，不常驻下载说明、存档状态或成功时间。“存档”按钮位于会话面板，成功后列表新增存档，失败时显示错误反馈。
- 点击“存档”将当前内存中的完整进度创建为新的“会话存档”，不覆盖原会话，也不重新执行 init。新存档成为本页的恢复基准，刷新恢复它；后续每次存档继续创建新副本。会话面板仍支持新建、切换、重命名和删除。
- 切卡、新建或切换会话时直接执行，不弹出存档确认，也不自动保存；未存档的内存进度被丢弃，已有存档不受影响。
- 删除当前会话会明确确认丢弃未保存修改；删除其它会话不会重新加载当前进度。删除最后一个会话后可从会话面板新建，不自动复活已删除会话。
- 刷新恢复最近一次显式保存的消息、变量、阅读位置和重试基准，然后执行既有卡片 init。init 仍可以按作者规则改变恢复结果，但不会自动写回存档。
- 页面离开只在有未保存进度时请求浏览器提醒；不在关闭事件中自动保存，提醒也不能保证在崩溃或所有移动浏览器上出现。

卡片和会话选择使用本标签页的 sessionStorage 辅助恢复；实际存档在 IndexedDB 中。新标签页有自己的当前选择，不能改变其它标签页的写入目标。资源下载仍使用 Cache Storage，不进入存档快照。

## 存储与事务

`WorldCardStationWeb` schema v3 增加 `sessions`，保留已有 `settings`、`backgrounds` 和 `cardReferences`。升级阻塞和存储失败均明确报错，不静默退回内存并声称保存成功。

会话作用域使用发布引用的 `key`，由可信来源 URL、cardId 和不可变 releaseId 共同确定；普通聊天使用独立的 `no-card`。同一作用域记录保存会话索引与快照，使下列字段在一个 readwrite 事务内提交：

```text
session: id / title / createdAt / updatedAt / revision / messageCount / preview
snapshot: messages / gameState / viewState / retryBaseMessages / retryBaseState
```

新作用域可创建空会话记录，但 init、回合完成、流式输出、自定义 UI 修改和阅读变化都不自动覆盖快照。重命名只修改标题；不会把内存中未保存进度带入数据库。

读取返回 `saveTarget: { scope, id, revision }`。Web 存档捕获内存快照，通过 `saveHistory(..., { saveTarget, asNew: true })` 在同一事务内检查来源会话仍存在且 revision 一致，然后追加新 ID 的完整快照与索引。原会话不变；成功后本页使用新 ID 作为恢复基准。不会先创建空档再分步写入，也不会在写入时重新查询共享的“当前活动会话”。来源已删除时拒绝迟到存档。

多个标签页可以基于同一会话各建独立存档，互不覆盖；来源会话被删除或 revision 改变时才拒绝操作，并保留本页内存、暂停存档与生成，提示重新加载。其它错误如配额不足允许重试，不改变旧档或留下空档。存档导出与跨端转移属于后续步骤，当前不提供导出入口。

## 运行时约束

- 保存内容包含完整消息 metadata、TTL、变量、阅读游标和 retry base；不包含模型配置、密钥或媒体 Blob。
- dirty 比较当前快照与最近恢复/成功提交的快照；保存中发生的新修改不会被错误标记为已保存。
- 初始化、生成、排队的 UI 状态/脚本操作及阅读状态 patch 未稳定时禁用保存；保存中拒绝新的生成和 UI 状态操作。
- 取消生成须等管线结束，再保存保留下来的未完成消息；保存不改变其生成完成标记。
- 恢复失败或数据结构损坏时禁止保存，不能用空状态覆盖旧档。
- retry 始终使用本轮发送前的内存基准，不从上次手动存档重新加载；成功保存后该基准也随快照持久化。

## 验证

`test/web/unit` 覆盖 dirty、保存期间修改、失败保留、直接切换不保存、作用域绑定和删除竞争。真实浏览器集成覆盖 IndexedDB 事务失败回滚、完整快照、来源/版本隔离及 revision 检查。生产页面 E2E 覆盖无自动保存、显式保存与刷新恢复、无弹窗切换以及双标签页冲突。

浏览器矩阵、原生桌面端完整验收及后续资源卸载/跨端转移仍按[开发计划](./web_development_plan.md)执行；单浏览器通过不代表全部正式交付门禁完成。
